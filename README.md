# TaskStack

TaskStack — настольный менеджер задач для Windows на Python и PyQt6. Приложение позволяет создавать задачи с категорией, приоритетом и сроком, искать и фильтровать список, отмечать выполнение, а также закреплять окно поверх других окон и сворачивать его в системный трей.

**Текущая версия: 1.0.0**

## Запуск из исходного кода

Требуются Windows и Python 3.11 или новее.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

При первом запуске приложение создаёт локальный `config.json`. Настройки интерфейса сохраняются в хранилище Windows через `QSettings`, а задачи синхронизируются с сервером задач.

## Сервер задач

В разрабатываемом обновлении 1.1 добавляются авторизация, совместное использование задач и групп. Для локальной разработки в первом терминале установите серверные зависимости и запустите API:

```powershell
python -m pip install -r requirements-server.txt
python -m uvicorn server:app --host 127.0.0.1 --port 8000
```

Затем запустите приложение во втором терминале. По умолчанию оно подключается к `http://127.0.0.1:8000`; для другого адреса задайте переменную окружения `TASKSTACK_SERVER_URL` перед запуском. Защищённые API-маршруты требуют входа по bearer-токену; новые пароли хранятся с PBKDF2-HMAC-SHA256, а старые SHA-256-хеши обновляются при успешном входе.

Для бесплатного размещения API поддерживает PostgreSQL через переменную окружения `DATABASE_URL`; если она не задана, используется локальная SQLite-база. Neon Free — вариант постоянной БД: по [текущим ограничениям](https://neon.com/docs/introduction/plans) бесплатный тариф не является пробным и не требует карты, но ограничен 1 ГБ, 100 CU-часами и 5 ГБ трафика на проект; вычисления засыпают после 5 минут бездействия. У бесплатного тарифа нет SLA и автоматических резервных копий. Бесплатный [Render Postgres](https://render.com/docs/free) истекает через 30 дней, а файловая система бесплатного веб-сервиса Render эфемерна.

Файл `render.yaml` подготавливает бесплатный веб-сервис с проверкой `/health`; перед его ручным первым deploy создайте проект Neon Free и добавьте pooled connection string (с SSL) из Neon Console в секрет `DATABASE_URL` сервиса Render. Blueprint не содержит значения секрета и отключает автоматические deploy. После подтверждённого deploy задайте `TASKSTACK_SERVER_URL` равным фактическому HTTPS-адресу Render-сервиса. При первом запуске сервер создаёт таблицы в PostgreSQL. Автоматического переноса локальной SQLite-базы нет: если требуется перенести существующие учётные записи и задачи, сначала нужно выполнить отдельную миграцию данных. Даже с Neon Free остаются ограничения тарифа и отсутствие SLA/автоматических резервных копий.

## Сборка Windows-приложения

```powershell
python -m pip install -r requirements-build.txt
python -m PyInstaller --noconfirm --clean --distpath release-build\dist --workpath release-build\work TaskManager.spec
```

Готовый исполняемый файл появится в `release-build\dist\TaskManager.exe`. Для запуска `.exe` Python устанавливать не нужно.

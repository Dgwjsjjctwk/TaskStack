# TaskStack

TaskStack — настольный менеджер задач для Windows на Python и PyQt6. Приложение позволяет создавать задачи с категорией, приоритетом и сроком, искать и фильтровать список, отмечать выполнение, а также закреплять окно поверх других окон и сворачивать его в системный трей.

**Текущая версия: 1.1.0**

## Запуск из исходного кода

Требуются Windows и Python 3.11 или новее.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

При первом запуске приложение создаёт локальный `config.json`. Настройки интерфейса сохраняются в хранилище Windows через `QSettings`, а задачи синхронизируются с сервером задач.

## Сервер задач

Обновление 1.1 добавляет авторизацию, совместное использование задач и групп. Для локальной разработки в первом терминале установите серверные зависимости и запустите API:

```powershell
python -m pip install -r requirements-server.txt
python -m uvicorn server:app --host 127.0.0.1 --port 8000
```

Затем запустите приложение во втором терминале. По умолчанию клиент подключается к production API `https://taskstack-o9vw.onrender.com`. Для локальной разработки переопределите адрес перед запуском:

```powershell
$env:TASKSTACK_SERVER_URL = "http://127.0.0.1:8000"
python main.py
```

Переменная `TASKSTACK_SERVER_URL` также позволяет указать собственный сервер. Старый сохранённый локальный URL автоматически заменяется на production URL; пользовательский адрес сохраняется. Защищённые API-маршруты требуют входа по bearer-токену; новые пароли хранятся с PBKDF2-HMAC-SHA256, а старые SHA-256-хеши обновляются при успешном входе.

Для бесплатного размещения API поддерживает PostgreSQL через переменную окружения `DATABASE_URL`; если она не задана, используется локальная SQLite-база. Neon Free — вариант постоянной БД: по [текущим ограничениям](https://neon.com/docs/introduction/plans) бесплатный тариф не является пробным и не требует карты, но ограничен 1 ГБ, 100 CU-часами и 5 ГБ трафика на проект; вычисления засыпают после 5 минут бездействия. У бесплатного тарифа нет SLA и автоматических резервных копий. Бесплатный [Render Postgres](https://render.com/docs/free) истекает через 30 дней, а файловая система бесплатного веб-сервиса Render эфемерна.

Production API размещён на [Render](https://taskstack-o9vw.onrender.com); `/health` проверен и отвечает успешно. Обновлённая проверка health также сообщает используемый тип БД и делает запрос к ней. Blueprint требует `DATABASE_URL` и отказывается запускать Render-сервис на эфемерной SQLite; для постоянного бесплатного хранения настройте Neon Free pooled connection string как секрет Render. Render Free может приостанавливать веб-сервис после бездействия, а Neon Free ограничен по объёму/вычислениям, не имеет SLA и автоматических резервных копий. Локальная SQLite-база не переносится автоматически; для миграции существующих учётных записей и задач требуется отдельная процедура.

## Сборка Windows-приложения

```powershell
python -m pip install -r requirements-build.txt
python -m PyInstaller --noconfirm --clean --distpath release-build\dist --workpath release-build\work TaskManager.spec
```

Готовый исполняемый файл появится в `release-build\dist\TaskManager.exe`. Для запуска `.exe` Python устанавливать не нужно.
